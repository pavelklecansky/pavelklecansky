### 🏋️ JinLog

[![JinLog](feature-en.png)](https://jinlog.app/)

Private gym log you write like notes: `bench 80x8,8,7` turns into sets, charts and personal records.
Works fully offline, no account, no ads. Your data stays with you as plain text files.

Svelte 5 · TypeScript · Capacitor (Android) · PWA · Astro

**[jinlog.app](https://jinlog.app/)**
